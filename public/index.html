Deployment & Setup Guide

Ikuti langkah-langkah di bawah ini untuk menjalankan sistem WA Classifier di server atau mesin lokal Anda menggunakan Docker.

1

Prasyarat Sistem

Pastikan perangkat Anda sudah terinstall komponen berikut:

  • Docker & Docker Compose
  • Ollama AI (Local)
2

Konfigurasi Environment

Salin file .env.example menjadi .env dan sesuaikan kredensial database Anda.

DB_USER=postgres
DB_PASSWORD=yourpassword
DB_NAME=wa_classifier
OLLAMA_URL=http://host.docker.internal:11434
3

Menjalankan Sistem

Gunakan satu perintah untuk membangun dan menjalankan semua layanan (Database, Engine, Dashboard).

docker compose up -d --build
4

Autentikasi WhatsApp

Pantau log docker untuk mendapatkan QR Code, lalu scan menggunakan aplikasi WhatsApp Anda.

# Lihat log bot
docker logs -f wa-filter-bot

Setelah scan berhasil, sesi akan disimpan secara permanen di folder wa_sessions.

Verifikasi Berhasil

Buka dashboard di http://localhost:3000. Status akan berubah menjadi Live Engine dan sistem siap menyaring pesan otomatis.
