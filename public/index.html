Integration Guide

1 Setup Database

Pastikan PostgreSQL sudah berjalan sesuai dengan konfigurasi di docker-compose.yml.

2 Import Logger

Tambahkan kode berikut ke bagian atas index.js:

const { saveLog } = require('./database');

3 Log Pesan

Panggil saveLog setelah proses filter AI/Keyword selesai:

await saveLog({
  sender: msg.from,
  sender_name: contact.pushname,
  message: msg.body,
  classification: isSpam ? 'JOKI' : 'SAFE',
  reason: filterType
});
